# БОРЕЙ — Продажа вездеходов на мостах «Волга»

Современный сайт для продажи вездеходов «Борей» с двигателями Lifan/Loncin. Разработан на Next.js 16 с использованием Tailwind CSS 4.

**Демо:** [allterrain-shop.vercel.app](https://allterrain-shop.vercel.app)

## 🚀 Особенности

- **3 комплектации** — Стандарт (520 000 ₽), Оптима (540 000 ₽), Профи (590 000 ₽)
- **Галерея изображений** — переключение фотографий товара по клику на миниатюры
- **Калькулятор лизинга** — расчёт ежемесячного платежа с настройками взноса и срока
- **Дополнительные опции** — лебедка, багажники, фаркоп, защита картера, камуфляж
- **Форма захвата лидов** — валидация телефона, отправка через Formspree
- **SEO-оптимизация** — мета-теги для каждой страницы (Open Graph, Twitter Cards)
- **Адаптивный дизайн** — мобильная, планшетная и десктопная версии
- **Доступность (a11y)** — ARIA-атрибуты, клавиатурная навигация

## 🚀 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/info-pvv/BFT.git
cd allterrain-shop

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен-сервера
npm start

# Линтинг
npm run lint
```

После запуска откройте [http://localhost:3000](http://localhost:3000)

## 🔧 Настройка форм

Для получения заявок на почту `info@terraforge.ru`:

1. Зарегистрируйтесь на [Formspree](https://formspree.io)
2. Создайте новую форму с вашим email
3. Замените `YOUR_FORM_ID` в файлах:
   - `app/catalog/[slug]/page.tsx` (строка ~277)
   - `app/contacts/page.tsx` (строка ~141)

```tsx
<LeadForm endpoint="https://formspree.io/f/YOUR_FORM_ID" />
```

## 🚀 Деплой на Vercel

### Через GitHub (рекомендуется):

```bash
# Инициализация Git
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ваш-username/allterrain-shop.git
git push -u origin main
```

1. Зайдите на [vercel.com](https://vercel.com)
2. Войдите через GitHub
3. Нажмите **Add New Project**
4. Выберите репозиторий `allterrain-shop`
5. Нажмите **Deploy**

### Через Vercel CLI:

```bash
npm install -g vercel
vercel login
vercel
```

### Настройка домена:

1. В настройках проекта на Vercel перейдите в **Domains**
2. Добавьте ваш домен (например, `terraforge.ru`)
3. Настройте DNS записи у регистратора домена:
   - **A record:** `76.76.21.21`
   - **CNAME:** `cname.vercel-dns.com`
