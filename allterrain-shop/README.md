# БОРЕЙ — Продажа вездеходов на мостах «Волга»

Современный сайт для продажи вездеходов «Борей» с двигателями Lifan/Loncin. Разработан на Next.js 15 с использованием Tailwind CSS.

## 🚀 Особенности

- **3 комплектации** — Стандарт (520 000 ₽), Оптима (540 000 ₽), Профи (590 000 ₽)
- **Страница товара** — галерея, характеристики, калькулятор лизинга
- **Дополнительные опции** — лебедка, багажники, фаркоп, защита картера
- **Форма захвата лидов** — валидация телефона, отправка через Formspree
- **SEO-оптимизация** — мета-теги для каждой страницы
- **Доступность (a11y)** — ARIA-атрибуты, клавиатурная навигация

## 🛠️ Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен-сервера
npm start

# Линтинг
npm run lint
```

После запуска откройте [http://localhost:3000](http://localhost:3000)

## 🔧 Настройка форм

Для получения заявок на почту:

1. Зарегистрируйтесь на [Formspree](https://formspree.io)
2. Создайте новую форму
3. Замените `YOUR_FORM_ID` в файлах:
   - `app/catalog/[slug]/page.tsx`
   - `app/contacts/page.tsx`

```tsx
<LeadForm endpoint="https://formspree.io/f/YOUR_FORM_ID" />
```

## 📝 Технические характеристики вездехода

### Ходовая часть и трансмиссия

| Параметр       | Значение                                          |
|----------------|---------------------------------------------------|
| **Мосты**      | Легендарные, усиленные мосты «Волга»              |
| **Коробка передач** | Новая КПП ВАЗ 2110 с автомобильным сцеплением |
| **Рама**       | Переломная рама шкворневого типа с усиленной крестовиной |
| **Управление** | Гидрообъемное (ГУР) на гидравлике, гидроцилиндр от трактора Т-40 |

### Двигатель

| Параметр         | Значение                          |
|------------------|-----------------------------------|
| **Варианты**     | Lifan или Loncin                  |
| **Мощность**     | От 20 до 30 л.с. (объем 460 см³ или 764 см³) |
| **Подача топлива** | Карбюратор                       |
| **Тип**          | Четырехтактный                    |
| **Ременной привод** | 3 ремня профиля А (Рубена)      |

### Грузоподъемность

- До **600 кг**

### Комфорт и проходимость

| Параметр     | Значение                                                      |
|--------------|---------------------------------------------------------------|
| **Колеса**   | Бескамерные колеса низкого давления «Краз-лапоть»             |
| **Салон**    | Лобовое стекло, основное водительское и переднее дополнительное пассажирское сиденье |
| **Хранение** | Вместительные рундуки для снаряжения под сиденьями пассажиров |
